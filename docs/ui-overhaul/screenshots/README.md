# Screenshots

Taken at 1600 x 900 with `docs/ui-overhaul/checks/*.mjs` (Playwright driving Edge) against a dev server.
Map tiles load over the network and the opening flight takes a while in software rendering, so a few frames catch the camera mid-move.

- `before/`: the old UI at commit `ec7a88b` (dark only, it had no light theme), both viewers, Story and Scientist.
- `after/`: the new UI, both viewers, Story and Scientist, dark and light.
- `states/`: tour card, period menu, Scientist inspector, layers tab, charts tab and the methods dialog, dark and light.
- `loading/`: opening splash frames (pixel build and fade), the story-switch skeleton, and the reduced-motion splash.
- `checks/`: the upward story and language menus, the Assamese dock with its machine-translation note, and a 1280 x 720 window.
